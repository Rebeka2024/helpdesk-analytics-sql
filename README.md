# 🖥️ HelpDesk Analytics SQL Project


## Overview

HelpDesk Analytics is a relational SQL database project designed to analyze IT support operations, ticket resolution trends, and service performance.


## Technologies Used

- MySQL
- SQL
- Relational Database Design


## Database Structure

### Employees
Stores support staff information:
- Employee name
- Department


### Customers
Stores customer information:
- Company
- Contact information


### Tickets
Tracks:
- Issue type
- Priority
- Status
- Resolution dates


## SQL Skills Demonstrated

- Database creation
- Table relationships
- Primary and foreign keys
- JOIN operations
- Aggregate functions
- Data filtering
- Date calculations
- Business reporting


## Business Questions Answered

- How many tickets are open?
- What issues occur most frequently?
- Which employees handle the most tickets?
- How quickly are issues resolved?
- Which high priority issues require attention?
